# Source art

The footballers are made from parts shared by all the 3D games, so their sources are with them in
[`web/people/source/`](../../../people/README.md): the MakeHuman parts, the CMU motion capture, and
Quaternius' animation libraries (moved there from here). The cast and its moves are recipes in
[`tools/people/recipes/`](../../../../tools/people/README.md).

Before that, the players were Quaternius' Universal Base Characters with the kit painted onto the skin.
That pack is now in City Runners' source folder, which still uses it.
